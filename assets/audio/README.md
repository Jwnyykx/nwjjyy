# 声音文件预留

此目录目前没有真实录音，也没有生成或合成的人声文件。

默认预留路径为：

```text
assets/audio/ni-za-yang.mp3
```

在确认录音相关人员同意公开之后，自行将 MP3 文件放到该位置，再把根目录 `site-config.js` 中 `audio.enabled` 改为 `true`。默认值为 `false`，页面显示「等一段特别的声音到来。」，不会请求不存在的 MP3 文件。

启用后使用页面按钮手动播放；网站不自动播放。若路径错误或文件无法加载，播放器会回到占位状态。

公开网站和公开 GitHub 仓库中的录音可以被别人保存或下载。不要上传未获得授权的私人录音，不能把网页上的播放按钮当成隐私保护。

完整修改、预览及发布说明见根目录 [README](../../README.md)。
