# 手机上使用《nwjjyy的故事》

正式开通后，用浏览器或 NFC 挂件打开 [故事书](https://jwnyykx.github.io/nwjjyy/)，点 **成员登录**，输入管理员为你开通的邮箱和密码。开通前，可以先按 [本机试用说明](README.md) 在电脑上走一遍流程。

## 写第一篇故事

1. 进入故事书，点 **写故事**。给这段回忆写个标题，选故事真正发生的日期和分类。
2. 在正文里写想记住的事。要做小标题、加粗或者引用时，可以用正文旁边的按钮。点 **预览** 可以先看看正文的阅读效果。
3. 点 **选择照片**，可以一起选多张 JPG、PNG 或 WebP。照片会自动生成缩略图。默认保存原图，取消勾选后，后续选择的照片会存为优化版。若手机相册给出 HEIC，可以先转为 JPEG。每份文件最大 15 MB。
4. 可以写照片说明、上移下移、设为封面。点 **插入正文**，照片会放在正文末尾，随后可以在编辑框里移动它的位置。也可以加 MP3、M4A 或 WAV 录音，读故事的人点击后才会载入播放。
5. 写完点 **发布**，等保存提示出来。新故事会进首页和时间轴。想晚点续写，就点 **保存草稿**，之后从 **更多 → 管理中心 → 草稿** 继续。

如果网络断开或上传失败，可以先留在编辑页，连网后重新提交。第一次稿件有可能已经存成草稿，可以从管理中心查到。选择的文件和还没保存的文字留在当前编辑页，关闭页面时请留意未保存提示。

## 平时怎么维护

- 打开故事详情点 **编辑**，改完点 **保存更新**。同一页下面可以各自点 **写下我的视角**，补写自己的记忆。
- **回忆相册** 可以按年份、分类或精选浏览，点照片放大，左右滑动切换。独立照片也能直接上传，作者或管理员可以改说明、替换或移到回收站。
- **更多 → 心动日记** 适合写一句话或短日记。勾选首页展示，发布后最近一条会进首页。
- **更多 → 未来的约定** 可以记录想一起做的事。做到后填写完成日期，也可以关联已经发布的故事。
- 管理员在 **更多 → 纪念日与故事书设置** 里添加纪念日、选时区、修改首页简介和登录后封面。私人封面从独立相册照片选择。
- 误删的故事、日记、约定和照片，可以在 **管理中心 → 回收站** 找回。恢复的照片会在所属故事或日记发布时回到相册。
- 想看看小兔子，登录后往首页下方翻，点 **书页里的小伙伴**。摸它一下看小碎步，连点三下有原来的彩蛋。

## 新版从哪里开始试

1. **故事 → 章节**。可与 **时间轴** 互相切换，两处读取同一份故事。管理员在 **更多 → 管理中心 → 管理章节** 新建章节、改封面和调整顺序。点进故事后，两位可以分别写一份视角，也可以收藏或重新回到上次读过的故事。收藏和阅读进度跟随当前设备上的账号。
2. **相册**。点开一张照片，再点 **翻到背面**。上传者或管理员可以编辑地点、摄影者、回忆和留言。在相册进入 **照片合集**，由管理员把选定照片排成一本小册。**回忆放映机** 可以按日期和分类播放照片，音乐需从本机主动选择。
3. **更多 → 我们的足迹**。用城市筛选相见记录。点 **记下相见**，填写城市和日期、关联几篇故事，保存后可以打开单次相见页。管理员还可以在设置里填写下次见面的日期。
4. **更多 → 写给你的信 · 时间胶囊**。写信时可选择信封、添加照片和声音。点 **留一份时间胶囊**，选好解锁时间再寄出。另一账号可先看到信封，到期后点 **拆开信封** 阅读。是否让对方在解锁前看标题、是否公开打开时间，由写信人选择。
5. **更多 → 找一段回忆**。可按关键词、日期或分类筛选记录。打开 **故事年鉴**，按发生年份翻阅，管理员可改标题、封面、年度感言和重点故事。使用 **打印当前年鉴** 可保存浏览器生成的 PDF。
6. **更多 → 小兔子邮差**。这里会显示实际收到的新信和已到期的时间胶囊，摸兔子也有原来的小碎步。**声音邮局** 里的录音要主动载入和播放。

管理员可在 **纪念日与故事书设置** 更改私人首页、配色、轻动画和邮差信件提示，也可在 **NFC 专属入口** 设置「特别故事」。登录后才可打开成员专属链接。隐藏故事适合藏在礼物入口，另一位成员也能通过链接读到它。

## 带走一份备份

在 **更多 → 备份与导出** 点 **准备备份**，下载记录 JSON 和逐批出现的媒体 ZIP。平时留存到两位可以访问的位置。从旧项目搬家时由管理员导出共享故事书，再按 [恢复说明](DATABASE.md) 操作。

信箱的 **导出我能阅读的信件** 单独保存当前账号可查看的信件与正文。打开信里可访问的照片或声音后，点 **保存附件** 下载原文件。
